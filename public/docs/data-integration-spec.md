# 数据接入规范(学校系统 → 专业建设智能诊断平台)

版本 v1 · 2026-10-15

## 1. 原则

- **不改造学校原有系统**:平台是中台,只要求学校按本规范把现有系统数据交出来。
- **三层来源,各归一类**:AI 自动采集(>85%)/ 学校系统导入 / 教师填报(仅教案、学情分析、形成性评价、综合性课程设计 4 类无源数据)。本规范只管第二层「学校系统导入」。
- **每次导入都留痕**:成功、部分失败、整体失败都会写入导入日志;失败会在「数据上传 → 数据源接入」页顶部告警。

## 2. 两种接入方式

| 方式 | 适用 | 做法 |
|---|---|---|
| 推送(推荐) | 学校系统能调用 HTTP 接口 | 按第 3 节调用 `POST /api/data-import` |
| 拉取 | 学校提供可读的接口 / 库 / 文件 | 管理员在「数据源接入」页登记端点、关联指标与同步频率,由平台按频率拉取 |

## 3. 推送接口

```
POST /api/data-import
Content-Type: application/json
X-Import-Token: <平台分配的导入令牌>
```

**鉴权**:服务器配置了 `DATA_IMPORT_TOKEN` 时,请求头 `X-Import-Token` 必须与之一致;未配置时改为管理员登录态鉴权。

**请求体**:

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `sourceSystem` | string | 是 | 来源系统名称,如「教务管理系统」 |
| `templateCode` | string | 是 | 数据对应的模板编号,见第 4 节 |
| `records` | object[] | 是 | 数据记录,每条是一个非空 JSON 对象;单次最多 5000 条,超过请分批 |
| `sourceId` | string | 否 | 在「数据源接入」页登记的数据源编号(如 `DS-07`),填了会同步更新该数据源的最近同步时间与状态 |
| `fileName` | string | 否 | 来自文件导出时的原文件名,便于追溯 |

字段命名以对应模板页(`/templates/t05` 等)的表头为准,中英文均可;平台按记录原样存档,由 AI 提炼后交教务确认。

**示例**:

```bash
curl -X POST https://<平台域名>/api/data-import \
  -H 'Content-Type: application/json' \
  -H 'X-Import-Token: <令牌>' \
  -d '{
    "sourceSystem": "教务管理系统",
    "sourceId": "DS-07",
    "templateCode": "T11",
    "records": [
      { "课程名称": "包装结构设计", "课程类型": "专业核心课", "学分": 3, "教学目标": "…" },
      { "课程名称": "智能包装技术", "课程类型": "专业选修课", "学分": 2, "教学目标": "…" }
    ]
  }'
```

**响应**:

| HTTP | 含义 | 响应体 |
|---|---|---|
| 200 | 全部或部分导入成功 | `{ success: true, logId, dataId, rowCount, successCount, errorDetail }`,`errorDetail` 非空表示有记录被跳过 |
| 400 | 请求不合规(缺字段、模板编号不对、超过 5000 条) | `{ success: false, error }` |
| 401 / 403 | 令牌无效 / 未登录 / 非管理员 | `{ success: false, error }` |
| 422 | 没有一条合格记录(已记入导入日志) | `{ success: false, logId, errorDetail }` |
| 503 | 平台数据库暂不可用,请稍后重试 | `{ success: false, degraded: true, degradedReason }` |

**注意**:接口不去重,同一批数据重复推送会产生两条存档;请在学校侧记录已推送批次,失败时只重推失败批次。

## 5. 导入日志与告警

- 每次推送 / 同步写一条导入日志:时间、来源系统、模板、行数、成功数、导入方、失败原因。
- 告警规则:近 7 天内有失败行的导入,以及状态为「离线」「降级」的数据源,显示在「数据源接入」页顶部。

## 6. 平台侧配置(运维)

| 变量 | 说明 |
|---|---|
| `DATABASE_URL` | SQLite 文件位置,如 `file:/app/data/app.db`;默认 `<项目>/data/app.db`。所在目录需挂持久卷 |
| `DATA_IMPORT_TOKEN` | 学校系统推送用的导入令牌,长随机串 |
| `API_REQUIRE_AUTH` | `true` 时所有接口要求登录,管理类接口要求管理员 |
